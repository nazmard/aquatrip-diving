📝 ブログ投稿ツール

八丈島アクアトリップダイビングブログの新しい記事を作るページです。写真も動画も、1つの記事に一緒に貼れます。動画はYouTubeやInternet ArchiveのURLを貼るだけなので、ブログが重くなることもありません。

対応するURL：YouTubeの動画ページ（youtube.com/watch…、youtu.be/…、ショートも可）／ Internet Archiveの動画ページ（archive.org/details/…）／ mp4ファイルのURL

公開の手順

  1. 上のフォームで記事を書いて「記事ファイルを作る」を押す（ファイルがダウンロードされます）
  2. ダウンロードしたファイルを、パソコンの aquatrip-diving\blog\posts フォルダに入れる（postsフォルダが無ければ作ってください）
  3. GitHub Desktopで Commit → Push origin
  4. 数分で公開され、「ブログ新着記事」のページに自動で並びます
