人口尾ビレのフジ

AQUATRIP (2005年3月13日 09:21) | コメント(0) | トラックバック(0)


＜バンドウイルカ＞人工尾びれのフジ、復活のジャンプ　沖縄

　人工尾びれをつけたバンドウイルカのフジ（メス、推定３５歳）が１２日、沖縄県本部町の海洋博記念公園で特別ショーに出演、高さ３．５メートルのジャンプを初めて披露した。
　水中でシリコンゴム製の尾びれを振ると、水しぶきとともに、体重２２５キロ、体長２７１センチの体が水面から飛び出し、観客７５０人から歓声が上がった。
　０２年秋に細菌感染症で尾びれの７５％を失い、泳ぐ気力をなくしていた。「もう一度、空高くジャンプさせたい」と、０３年７月に水族館とブリヂストンが人工尾びれの研究を始め、改良を重ねた。
　トレーナーの古網雅也さん（２６）は「尾びれを切除した時には、再び跳ぶことができるなんて想像できなかった」と感慨深げ。特別ショーは１日限りだが、今後も観客にジャンプをみせる機会があるという。【中村宰和】
（毎日新聞） - 3月12日20時14分更新

先日テレビでも放映され話題になった沖縄美ら（ちゅら）海水族館の「フジ」は推定年齢３５歳ぐらいだという。尾びれが無くなった原因は感染症による物だと言われているが、水族館の管理されたプールで感染症って起こるんだ～・・・って思いました。野生ならもちろんそんなことがあれば死に至ってしまうであろう重大事項だが、それは自然なことであって、尾びれが無くなっても生きている方が不自然だったのだと思う。
しかし、今後プロテクターを着けなくてもある程度泳ぐ事が出来るようにトレーニングされているらしいので
プロテクターが無ければ泳げないと言うことではないらしい。
野生に戻るのは今後一生無理だし、水族館で寿命まで生きるしかないのだ。
メスなのですでに何頭か出産をしているらしいのだが、これからも子孫を残して欲しい！

人間はダイビングで海に潜るとき、フィンなしではほとんど進まない。
トレーニングでフィン無しで泳ぐと、じれったいほど進まないし、体力とエアーも使ってしまう。
フィンのありがたみを一番知っているのは人間かも知れない。
だから、イルカの「フジ」がどれほど不自由で辛い思いをしているのかトレーナーや飼育係の人たちが
一番よく知っていらっしゃるのだと思う。
私はフィンは基本的に裸足で履くのだが、新品の真新しいフィンを履くときにいつも悩むことがある。
それは、靴擦れならぬフィン擦れなのだ。　特に左右の足の形が違うみたいで、右足の親指の付け根がフィンに当たり、毎回皮がむけて血が出てきてしまうのだ。今ではタコのように肉が盛り上がって頑丈になってらしいが・・・(*^_^*)　最初の頃は痛くてたまらなかったのを覚えている。
イルカの「フジ」もきっと、新しいフィンに馴染むまで少し痛い思いはあるのかも知れない。
シリコンラバーとカーボンファイバーのプロテクター・・・、ブリジストンの最高技術を結集して出来たイルカのフィン、まめなメンテナンスと、改良でフジにとって最高の「足」になるよに祈っています。

Skype とは、世界中どこへでも無料コールが、今すぐお楽しみいただける、操作が簡単な無料のソフトウェアです。世界中で人気の KaZaA のクリエーターたちによって製作された Skype は、P2P（peer-to-peer）テクノロジーによって、他の Skype ユーザーと接続します。高い通話料金にうんざりしている方に、ぜひお勧めのテレフォニーソフトウェアです！

Skype のダウンロードは、素早くとても簡単。ダウンロードする から登録を済ませれば、お使いの PC にヘッドホンをプラグインし、Skype ユーザーのお友達に通話できる環境が、ほんの数分で整います。しかも Skype のコールは、素晴らしい音質とエンドツーエンドの暗号を使用した高いセキュリティを兼ね備えています。そして何よりも、ファイアウォールやルータのコンフィギュレーションが一切必要なく、すぐにお使いいただける手軽さが、Skype の優れた利点です！

南鳥島（別名：マーカス）　

AQUATRIP (2005年3月 4日 20:22) | コメント(0) | トラックバック(0)

今日、ある方からメールで問い合わせがあった。　南鳥島へ行く方法についてだった。 昔一度だけ行ったことがあるので写真とそのときの雰囲気などをHPに載せてあるのだが南鳥島を知っている人はきっと１００人に２人ぐらいだと思うので少しだけ紹介しよう。 最近中国が騒いでいるのは沖ノ鳥島で、アホウドリで有名なのは鳥島。南鳥島と名前が付いてはいるが、実は日本の最東端なのだ。 東京から八丈島までが300km、小笠原までが1000kmそして南鳥島へは、なんと2000kmもあるのだ。 現在気象庁の測候所があり、それを支援する自衛隊と保安庁が駐在する。人口はおよそ４０人ぐらいで、一般人は立ち入り禁止なのだ。 芝浦から４００トンの貨物船で片道４日かかる。往復でなんと８日間！！「たまこっち」を３匹育てるにはちょうど良い日数だったのだ・・ ・笑 何をしに行ったのかって？それは、極秘任務で・・・・なんてウソ！伊豆七島海運が運ぶ水素ボンベの運搬作業員なのだ。 八丈島から東京までの往復船代と、給料１３日分が出るのだ。船の中では１日４食出て、 ひたすら甲板で本を読みながら日光浴をしていたのだ。 現地に着いてからの作業は、 １日目は船底にあるコンテナかごにクレーンのワイヤーのフックを４カ所かけるという非常に軽作業の担当となり、２日は艀で陸上作業・・ ・これがキツかった！のどは渇くし、ボンベは重いし、そしてとんでもなく暑いのだ！すぐ下はマリアナ諸島ということもあり、 真っ白な珊瑚のビーチとヤシの木が生い茂る熱帯気候なのだ。サイパンで真っ昼間に土木作業をやるようなもんだ・・・笑でも、 無事に作業が終わると風呂はあるし、建物の中はクーラーが効いている♪とっても天国だ。

作業は昼間にやるのだが、母船は沖に停泊している、夕方にはまた艀で船に帰り、夜は飲むか釣りを楽しむかだ。 釣りといっても半端じゃないよ！　ロープの先に大きな針とえさを付けてただ投げるだけで大きなカンパチとかが釣れちゃうんだもん！ 　美味しかったのはカッポレだった！　カッポレはヒラアジの総称だが詳しい種類はわからなかった。毎晩お刺身には困らなかったのだ。 ３日間の作業が終わって最終日の午後には島内観光が出来た。島内といってもわずか１５分もあれば一周してしまうような小さな島なのだが、 アジサシはいっぱいいるし、椰子の実も沢山落ちている。５個も拾ったら持ちきれないんだよ・・・笑そして、 少しだけシュノーケリングをやった！リーフ内でだったが、見慣れない魚が沢山見られてたのしかった。 自衛隊のYS-11が１週間に１回やってくるとのことで、現地の方に案内して頂いて滑走路で着陸を間近で見ることが出来た。そして、 また片道４日間かけて東京へと向けて出航したのである。またまた日焼けに挑戦したが、他にやることがない・・・笑ひたすら「たまごっち」 で遊ぶだけなのだ。 というわけで、キツかったけど楽しい南鳥島での思い出が出来たのだが、 南鳥島に興味がある人が意外にも多いと言うことがわかって少々驚いている。インターネットで探してみると掲示板などがいろいろあり、 情報を交換している模様である。一般人が立ち入り禁止となっているのに行ったことがある人のHPもたくさんあるみたいだ。 日本には沖縄以外にもこんな楽園みたいな南の島が、それも東京都にあると言うことをもっと知ってもらいたいと思います。 そして将来一般人に開放してもらって観光で気安く行けるようになればいいな～♪なんて軽はずみに思ったりもします。 　そのときにはマーカスでダイビングサービスでも始めようかな？

エントリーを書いているときにハイパーリンクを設定するのだが、デフォルトでは新しいページで開く設定は出来ないので、手動で" target="_blank"を指定するのだが、あるページを見ていたら、mt.jsスクリプトをいじるとデフォルトで新しいページで開くリンクを設定できるとのこと。

MTフォルダの中のmt.jsをテキストで開き、function insertLinkの最後の方の部分に　"target="_blank"を付け足すらしい。さっそく自分でもやってみた。

function insertLink (e, isMail) {
if (!canFormat) return;
var str = getSelection(e);
if (!str) return;
var my_link = isMail ? prompt('Enter email address:') : prompt('Enter URL:', 'http://');
if (isMail) my_link = 'mailto:' + my_link;
if (my_link != null)
setSelection(e, '<a href="' + my_link + '" target="_blank">' + str + '</a>');

太線の部分を付け加えるのだ。そして保存して再構築！普通に記事を書いてハイパーリンクの設定をしてあげると新しいページで開く設定が自動的に出来ているのだ＾＾ちょっと便利になりました。

ちなみに　AQUATRIPDIVING　のホームページは新しいウィンドで開きます♪

私の視力は今でもおよそ1.2～1.5はあると自信を持っている。 子供の頃からいままで一度もめがねやコンタクトを使ったことがないのだ。 最近スタイルシートの編集やなんやらをずっとやっていると、いつしか目がモニターに釘付けになってしまうのだ。ディスプレイの解像度は１７インチで1280×1024pxなので文字は相当細かく見える。 ４０を過ぎてから急激に始まった遠視？（私はこう呼んでいるが実は老眼らしい？）が日を追って進行しているのだ。１００円ショップで買った老眼鏡を使ってみるとあら不思議！細かくて見えにくかった文字が実に鮮明に見えるではないか！！水中でもたまに小さなウミウシや甲殻類を見るときに虫眼鏡を活用しているのだが、もうこれ無しでは潜れないほどになってきている。 しかし、逆に遠くの物は相変わらずよく見えるのだ。アフリカのマサイ族やなんとか族の人たちの視力が５とか６とかテレビでやっていたが、私も少なくとも遠くの物に関してはものすごく自信があるのだ！去年ボートで八丈小島に向かって走っていたとき沖の水平線にイルカが泳いでいるのをいち早く発見した事があった。何百メートルも沖のイルカの背びれが見えたのだ＾＾太陽の光が水面で反射したり、波が立ったりしているので非常に見分けが付きにくいのだが、それが絶対に背びれであることを一目見て絶対の自信を持てたのは過去にイルカの背びれが水面でどのように見えたかを記憶しているからだと思う。 水中では、虫眼鏡の併用で1cmほどのウミウシでもよく見えるのだ、（裸眼だと絶対に無理だが・・・笑）そしてデジカメでの撮影の時にはモニターが小さくてよくわらないことがほとんどなのだが、マクロ撮影は被写体からおよそ２０ｃｍでデジカメを構え、モニターを覗くにはさらに腕を伸ばして５０ｃｍ以上は離れるのだ！だからいつもマクロの時には少しだけズームをかけてモニターに映る被写体を拡大しているのだ。このごろマスクレンズが下半分が老眼鏡になっていたらいいなぁ～と真剣に思うようになってきた。
