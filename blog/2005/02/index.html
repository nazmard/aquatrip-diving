MTWeather　その３　成功です！！

AQUATRIP (2005年2月26日 03:35) | コメント(0) | トラックバック(0)

＊注意：「\」と表示されている部分は全て半角の「￥」の事ですので注意！

やりました！
パソコン師匠にいろいろ迷惑もかけましたが、最終的に「Jcode.pm」という
Perl に組み込むモジュールが足りなかったのが原因でした。
早速Jcode-1.99_06.zip を上記サイトからDLしてPerlのライブラリーにぶち込み
（私の場合は「C:\Perl\lib」にフォルダの中身をコピーした）念のためDOS窓を立ち上げて
「cd c:\」と打ち「c:\>」と表示されたら\Perl\bin\perl.exe D:\☆☆☆\☆☆☆\RebuildIndex.cgi
と入れる。　☆の部分は自分のmt.cgiが置いてあるフォルダのパス。
すると今までうんともすんとも言わなかったDOS窓がウェイティング状態になりしばらくすると
「->Access:
https://nazmard.github.io/aquatrip-diving//☆☆☆/mt.cgi?__mode=rebuild&blog_id=1&typ
e=index&next=0&offset=&limit=&total_entries=26&
is_bm=&entry_id=&is_new=&old_stat
us=&username=☆☆☆&password=☆☆☆ -> OK」
と出ました！！　☆の部分はIDとパスワードです。
DOS窓で確認出来たのですぐにcronでテストです。
crontabに　「*/2 * * * * C:\Perl\bin\perl.exe D:\☆☆☆\☆☆☆\RebuildIndex.cgi」
と入れてサービスを再起動。
（コントロールパネルから管理ツール→サービスでPython Cron Serviceをクリック）
すると２分後にDOS窓が立ち上がり先ほどのテスト状態のように何も表示されない真っ黒画面となり
１０秒ほどで自動的に消えた！その間HDDのアクセスランプがチカチカと激しく点滅し、
再構築をしている模様！！・・・感激です・・・(T_T)
今度はMTにログインしてメインテンプレートを少し変更して保存、再構築をかけないで閉じ、
メインページが表示されたままのブラウザーを見つめながら待つこと２分、
するとまたDOS窓が立ち上がり先ほどの作業をしている様子・・・泣！！
DOS窓が消えたらページをリロード！！　
すると先ほど変更した部分が見事に再構築によって変更されているのだ♪
２日間悩んでパソコン師匠にいろいろ面倒を見てもらったのが解決への道に繋がったのだ！
Jcode.pmが無いなんてやはり素人にはわかりません～(>_<)
DOS窓でいろいろやっているうちに変なメッセージが出て師匠に伝えたところ判明したという
訳なのだがただ単に「Perl」の最新版を入れたから問題ないと思ったところに落とし穴があったのだ。
めでたしめでたし！！

mt-rebuild.pl

AQUATRIP (2005年2月24日 20:49) | コメント(0) | トラックバック(0)

先日MTWeatherを入れたので６時間ごとにメインINDEXを再構築してデータを入れ替えないといつまで経ってもデータが更新されないのだ。

そこで、mt-rebuild.plを cron（pycron Version 0.5.1）で自動更新させようと思い、いろいろと試してみた。Windows xp pro　でHTTPDによる自宅サーバー環境での実験です。

まず、cron自体はunix環境で動作する物なのでWindowsで動作するmt-rebuild.plを cron（pycron Version 0.5.1）を私のパソコン師匠に教えてもらいインストールし、 コントロールパネル→管理ツール→サービスで起動させる。パソコン師匠はなんでも教えてくれるのだ♪

crontabで１行目に10 0 * * *"d:￥☆☆☆￥☆☆☆￥mt-rebuild.pl"を設定、２行目からは0を6、 12、18、に変更して全部で４行書く。最初の数字10は～時１０分に・・・と言うことだ。☆の部分は自分のmtフォルダへのパス。　さて、 ここまで出来たら当然自信満々で動いて当然！？と思っていたのだが・・・案の定ログファイルには～は有効な Win32 アプリケーションではありません。と表示されている！なんでなの～？残念！！

結局設定ミスなのかなんなのかわからないまま断念してしまった・・・。あとでパソコン師匠に聞いてみよっと！

MTWeather設置しました。

AQUATRIP (2005年2月21日 05:12) | コメント(0) | トラックバック(0)


MTWeather　からプラグインを入れて、八丈島の天気情報を
表示できるようにしてみました。　天気予報と、降水確率が表示されます。
風向きや波の高さがあったらもっといいなぁ～って思ったけど
データそのものはワンクリック気象情報から引っ張っているらしいので
無理みたいです・・・。花粉情報も表示できるのですが、ゴチャゴチャしすぎるのでやめました。
とりあえず、天気、気温、降水確率が出るのでまあまあかな？
風向きの情報はピンポイント天気情報で確認できますので我慢してくださいね♪
ここから風向きだけ抽出できないのかな～？・・・。
設置に関してはMTWeatherに詳しい情報が載っています。
ポイントとしては、表示されている使用例のタグに必要なタグを付け加え、スタイルシートもコピペすれば
グレーの背景でとりあえず表示されます。
あとは好みに応じてスタイルシートで背景を変えたり文字色を変えたりすればOKです。
わかってしまえば簡単ですが、タグの追加を
alt="<$MTToday$>">＜br＞<$MTTodayMax$>＜br＞<$MTTodayMin$>＜br＞　の様に
＜br＞の次に付け加えていくのがポイントです。もちろん表示させたい順番にやればOKです。

Movable Type 導入で一番理解できなかったのがデータベースという存在です。
Movable Type を動かすためのものだと言うことはわかるのですが、どうやってインストールするのかが
まったくわかりませんでした。
結局　BerkeleyDB　というところでDB File-1.806.zip　をダウンロードしてCドライブにDB_File-1.806 フォルダを作りコピーして、コマンドプロンプトでcd c:\ →cd DB_File-1.806→ppm install DB_File.ppd　と打ち込めばインストールされると言うことなのだが、私の場合いつまで経ってもコマンドプロンプトが動かずに、無効な・・・とかなんとかかんとか言われ続け、途方に暮れるのでした。
ふとActivePerlのバージョンか？と思い、念のため最新バージョンを入れ直し再度コマンドプロンプトを立ち上げ・・・なんと成功なのである！！　こんな簡単に行くんだったら一晩中悩まなくても良かったのにぃ～＾＾；ちなみにバージョンは
5.8.6.811になった。　あっけない幕切れであった。

その次に悩んだのがログインした後の設定でサイトのURLを　https://nazmard.github.io/aquatrip-diving/blog　としたところ、いつまで経っても表示できませんってブラウザが意地悪をするのです。
サーバソフトの設定なのか、Movable Typeの設定なのか結局わからず、また一晩悩むことに・・・笑
Movable Typeフォルダをいろんな所に置いて（cgiフォルダやcgi-binフォルダなど）設定し直したり、再起動したり、して最終的にblogフォルダに入れて設定し直したら何かの気まぐれか？ブラウザにトップ画面がいきなり表示されました・・・笑　あっけにとられて見ていたけど、結局原因がわからずじまいで偶然？
直ったとしか言いようがありません＾＾；
ちょっとだけパソコンを蹴っ飛ばしたせいなのか？何はともあれ、ここまで来るのに約２日・・・(*_*)

帰島開始

AQUATRIP (2005年2月 6日 07:07) | コメント(0) | トラックバック(0)


ついに三宅島帰島が始まった。２月５日、上京の予定があり、八丈島から東京へ向かう飛行機の機内の中から三宅島上空で三宅島の全景を撮影した。　ちょっと見にくいかも知れないが、上空の雲に混じって噴火口から噴煙が出ている。スクーバダイビングでは地元で空気をタンクに詰めて製造するが、特殊なフィルターにかけて清浄してからコンプレッサーにかけるそうなのでダイバーへのエアーの影響はないものと思われる。しかし、受け入れ態勢が本格的に整うのはまだ少し先の話のようだ。気の早い釣り客は６日に三宅島入りして周囲を困惑させているようだが、三宅島の話では５月以降に観光客（釣り客、ダイバーを含む）を本格的に受け入れる体制を作るため目下関係各所と連絡を取りながら体制を整えているようである。５月・・・具体的にはおそらくゴールデンウィークを目指していると思われるが、宿泊、ボート、充填所、緊急対策マニュアルなど、まだ課題が多いのは確かなようだ。一刻も早く観光客が再び三宅島の海を堪能できるように八丈島からもエールを送ります！！

キョン

AQUATRIP (2005年2月 2日 21:42) | コメント(0) | トラックバック(0)



植物公園に撮影に行った。なんでも「フェネック」というクルマとアウトドアの月刊誌で今回発表された「外来種生物規制」にキョンが含まれ、どんな生き物なのか紹介するのと、ブラックバスのようにそれほど数は多くないのに可愛そう…と言うことを記事にするみたいです。なので、朝早くまだ雪が降る中キョンの撮影をしましたが、雪が降っていたのでキョンもとっても寒そうです、なかなか小屋から出てきません！近くに落ちていた葉っぱをえさにおびき出してすかさずフラッシュ攻撃！しばらくすると葉っぱの催促でとっても忙しかった(>_<)でも、なんでキョンが外来種生物規制に入ったのかよくわかりません。生態系に影響があるなんて事もないし・・・（八丈島では檻の中できちんと飼育されています）万が一野に放たれたときにはきっと植物を食い荒らすとは思うけど・・・。でも、その前になんで東南アジア原産のキョンを八丈島の植物公園の中で飼育しているのか、わかる人教えてください！

積雪

AQUATRIP (2005年2月 2日 06:56) | コメント(0) | トラックバック(0)


昨日から降り出した雪がうっすらと積もりました。気温もぐっと低くなりついにハロゲンヒーターを使ってしまいました(*_*)でも、まだ石油ファンヒーターは使っていません！コタツもホットカーペットも使わずにこの冬を過ごす事に挑戦しています。子供からは「寒い、寒い！」とブーイングですが子供は風の子！一緒に頑張っています。昔八丈島に来た頃、修業時代にすきま風の掘っ立て小屋に住んでいたとき、暖房がないので仕方なくドライヤーで布団を暖めて寝ていた記憶が甦ってきます。１日５００円生活で食費も切りつめていた頃の話です。あのころは朝昼ともカップラーメンで過ごしていたっけ・・・(>_<)何にもなかったけど、毎日潜って幸せだったなぁ～！
