📝 ブログ投稿ツール

八丈島アクアトリップダイビングブログの新しい記事を作るページです。写真も動画も、1つの記事に一緒に貼れます。
公開と削除は、下の「GitHub接続」をした本人だけができる仕組みです（接続キーが無い人は、公開も削除もできません）。

🔑 GitHub接続（本人確認）

公開・削除には、あなたのGitHubアカウントで発行した「接続キー」が必要です。キーはこのブラウザの中だけに保存され、サイトや記事には残りません。キーが無い人はこのページを開けても、公開・削除ボタンは動きません。

未接続です

対応するURL：YouTubeの動画ページ（youtube.com/watch…、youtu.be/…、ショートも可）／ Internet Archiveの動画ページ（archive.org/details/…）／ mp4ファイルのURL

🗑 記事の管理（削除）

公開中の記事の一覧です。削除はGitHub接続をした本人だけができます。削除すると、数分でサイトからも消えます（GitHubに履歴は残るので、あとから復活もできます）。

公開の手順（接続している場合）

  1. 「GitHub接続」で接続する（キーの貼り付けは初回だけ）
  2. 記事を書いて「そのまま公開する」を押す
  3. 数分で公開され、「ブログ新着記事」のページと旧ブログの新着ボックスに自動で並びます

公開の手順（接続していない場合）

  1. 「記事ファイルを作る」を押す（ファイルがダウンロードされます）
  2. ダウンロードしたファイルを、パソコンの aquatrip-diving\blog\posts フォルダに入れる
  3. GitHub Desktopで Commit → Push origin
